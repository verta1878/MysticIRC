# Retired Files — 2026-09-09

Files moved to attic/ this session. All functionality replaced by
mystic/mdl/m_serial/ (MDL serial stack) and mystic/mystfoss.pas.

## attic/examples-serial/

**Was:** `examples/serial/` — standalone serial/FOSSIL examples.

**Why removed:** Duplicate code. `serial.pas` and `serial_irq.pas` are the
old standalone UART drivers superseded by `mystic/mdl/m_serial/m_serial.pas`
and `mystic/mdl/m_serial/m_serial_irq.pas`. `fossil.pas` and `netfosdl.pas`
are superseded by `mystic/mystfoss.pas`. `fostest.pas`/`fosfull.pas` are
test harnesses for the old FOSSIL — use mystfoss directly instead.

## attic/examples-netfosdlv1/

**Was:** `examples/netfosdlv1/` — v1 of the standalone DOS FOSSIL driver.

**Why removed:** Same code as examples/serial/ with prebuilt DOS binaries.
All replaced by mystfoss.pas which uses the MDL serial stack, compiles on
5 platforms (go32v2, i8086, win32, win64, os2), and has full X00/BNU serial
compatibility (15 FOSSIL functions). See the comparison in this session's
transcript — netfosdlv1's 9 console functions ($0D-$17) were stubs returning
zero anyway.

## attic/mystic_modem-removed/

**Was:** `mystic_modem/mdm_serial.pas`, `mystic_modem/mdm_modem.pas`,
`mystic_mailer/mlr_binkp.pas`

**Why removed:**

- `mdm_serial.pas` — wrapped FPC's RTL `Serial` unit. Replaced by
  `mystic/mdl/m_serial/m_serial.pas` (TModemSerial class) which talks
  directly to the OS on all 6 platforms without the FPC Serial dependency.
  The FPC Serial unit doesn't exist on i8086, so mdm_serial blocked
  DOS cross-compilation.

- `mdm_modem.pas` — Hayes AT modem control class (TModem). Functionality
  inlined directly into `mystic_misdos/misdos.pas` as helper functions
  (SendAT, ModemInit, IsRinging, AnswerCall, HangUp). No separate modem
  abstraction needed for the WFC example.

- `mlr_binkp.pas` — BinkP-over-serial detection seam. Not needed for the
  WFC example. Mystic's built-in BinkP engine (mis_client_binkp.pas) handles
  real BinkP sessions over TCP.
