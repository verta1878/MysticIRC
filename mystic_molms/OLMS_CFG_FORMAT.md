# OLMS.CFG Binary Format Specification

Reverse-engineered from the OLMS 2000 distribution (Cosmo's Castle BBS).
Total file size: 14,889 bytes.

## String fields

All strings are Pascal-style: 1-byte length prefix + up to 60 bytes
of ASCII data, padded to 61 bytes total per field.

## Notes

- The config file was generated by CONFIG.EXE for "Cosmo's Castle BBS"
  (sysop: Leslie Given)
- Archiver fields are 71 bytes (length prefix + 70 byte max)
- The file contains extensive null-padded regions between sections,
  likely reserved for expansion or for the professional version's
  10,000-conference support
- String encoding is CP437 (standard DOS)
