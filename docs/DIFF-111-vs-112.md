## Item 4: m_prot* Files Location

**PROBLEM:** In both 1.12 and our repo, m_protocol_*.pas files are in
the source/ (or mystic_test/) directory. They should be in mdl/ since
they're MDL library units, not BBS-specific code.

**Current state:**
- `mystic_test/m_prot_binkp.pas` — should be in mdl/
- `mystic_test/m_protocol_binkp.pas` — should be in mdl/
- `mdl/m_prot_base.pas` — correct location ✅
- `mdl/m_prot_zmodem.pas` — correct location ✅
- `mdl/m_protocol_*.pas` — some already in mdl/ ✅

**Fix:** Move all m_prot* and m_protocol* from mystic_test/ to mdl/.
No code changes needed, just file relocation + compile path update.

## Item 5+: Additional Issues from Testing

    442 bytes consumed by new fields. Our RIP fields (6 bytes) are in

## Item 12 Expanded: Editor Changes in 1.12

### ANSI Editor (bbs_edit_ansi.pas)
- Upload ANSI option in draw mode menu
- Upload no longer strips ICE/blinking colors
- Block operations: CTRL+B select, fill, center text
- "CRLF at EOF" option (default Yes)
- "File saved" confirmation box
- Retains filename between save dialogs
- CTRL+X exit with save prompt
- Delete key allows file deletion
- Save bugfixes (saving without extension)
- New buffers default to "Clear Screen Yes"
- Supports terminal-sized editing (not hardcoded 80x25)
- Can load PCBoard, Wildcat, Mystic pipe codes, and ANSI
- Can save in ASCII or ANSI format

### Text Editor (bbs_edit_full.pas / new text editor)
- **NEW: Built-in text editor** (separate from FS message editor)
- Available in System Configuration > Other > Text Editor
- CTRL+J Jump to line number
- CTRL+W Where (boolean search)
- CTRL+A Again (repeat last search)
- (Q)uit changed from e(X)it to match ANSI editor
- Uses full terminal size (not hardcoded)
- View-only mode (backspace disabled)
- Detects changed files properly

### Full Screen Message Editor
- **Converted to .ini template system** (msg_editor.ini)
- Template files: msg_editor.ini, msg_editor.ans, msg_editor_quote.ans, msg_editor_help.ans
- Prompts #354, 355, 356 removed — display files ansiquot/ansiedit/fshelp no longer used
- Spell checking with Hunspell (word suggestions, on-the-fly)
- Taglines built into editor (mode configurable per user)
- Multi-resolution templates (msg_editor.c132x36.ini etc.)
- Better reformat logic on backspace
- Save as draft option
- Cut/paste bugfix

### Config Editors (general)
- All editors list by unique ID
- String input allows more characters
- ESCAPE during string input cancels
- First key no longer erases entire input
- iCE/blink color support in color editors
- User Editor: paged form, CTRL+A create user, "never delete" flag
- Menu Editor: selectable command box, /T template, max items warning
- Prompt Editor: reset function, source display
- Group/Base editors: move function, /A select all, /G global editor
