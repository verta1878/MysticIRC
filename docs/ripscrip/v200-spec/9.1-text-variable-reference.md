# 9.1 Text Variable Reference

[◀ Prev: 9.0 Command Reference](9.0-command-reference.md) · [Contents](README.md) · [Next: 9.2 Version Identification Reference ▶](9.2-versions.md)

Every pre-defined [text variable](../../glossary.md) in RIPscrip 2.x, with its parameter form, type, and effect, linked to its full entry. **Value** variables return text to the host; **Active** variables perform an action on the terminal (some also return data when used to query). Parameters shown in parentheses are optional unless the entry says otherwise; the 2.x parameterized forms supersede the 1.54 fixed names (`$SAVE(8)$` vs `$SAVE8$`).

_User-defined variables - any `$IDENTIFIER$` with the `*`/`+`/`=`/`#`/`-`/`&` reference modes, positioning, questions, defaults and format options - are covered in [5.1 Text Variables](5.1-text-variables.md#text-variable-creation-and-query); variables removed or renamed since 1.54 are listed in [5.1's rename note](5.1-text-variables.md)._
