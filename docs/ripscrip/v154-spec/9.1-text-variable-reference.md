# 9.1 Text Variable Reference

[◀ Prev: 9.0 Command Reference](9.0-command-reference.md) · [Contents](README.md) · [Next: 9.2 Version Identification Reference ▶](9.2-versions.md)

Every pre-defined [text variable](../../glossary.md) in RIPscrip 1.54, with its type and returned format, linked to its full entry. **Value** variables return text to the host; **Active** variables perform an action on the terminal and return nothing.

_User-defined variables (any `$IDENTIFIER$` of 1-12 characters) are covered in [5.1 Text Variables](5.1-text-variables.md#user-text-variables)._

## Date & time

| Variable | Type | Returns / Action | Entry |
| --- | --- | --- | --- |
| `$DATE$` | Value | Date in short format, `MM/DD/YY` | [5.1](5.1-text-variables.md#date) |
| `$MONTH$` | Value | Full month name (e.g. `December`) | [5.1](5.1-text-variables.md#month) |
| `$MONTHNUM$` | Value | Month number, 01-12 | [5.1](5.1-text-variables.md#monthnum) |
| `$DAY$` | Value | Day of month, 01-31 | [5.1](5.1-text-variables.md#day) |
| `$DOY$` | Value | Day of year, 001-366 | [5.1](5.1-text-variables.md#doy) |
| `$YEAR$` | Value | 2-digit year | [5.1](5.1-text-variables.md#year) |
| `$FYEAR$` | Value | 4-digit year | [5.1](5.1-text-variables.md#fyear) |
| `$TIME$` | Value | Time in military format, `HH:MM:SS` | [5.1](5.1-text-variables.md#time) |
| `$HOUR$` | Value | Hour, 01-12 (non-military) | [5.1](5.1-text-variables.md#hour) |
| `$MHOUR$` | Value | Hour, 00-23 (military) | [5.1](5.1-text-variables.md#mhour) |
| `$MIN$` | Value | Minutes, 00-59 | [5.1](5.1-text-variables.md#min) |
| `$SEC$` | Value | Seconds, 00-59 | [5.1](5.1-text-variables.md#sec) |
| `$AMPM$` | Value | `AM` or `PM` | [5.1](5.1-text-variables.md#ampm) |
| `$DATETIME$` | Value | Unix-style date/time (e.g. `Sat Dec 19 14:38:50 1993`) | [5.1](5.1-text-variables.md#datetime) |
| `$TIMEZONE$` | Value | Time zone abbreviation, or `NONE` if unknown | [5.1](5.1-text-variables.md#timezone) |
| `$DOW$` | Value | Day of week, fully spelled out | [5.1](5.1-text-variables.md#dow) |
| `$ADOW$` | Value | Abbreviated day of week (`Sun`-`Sat`) | [5.1](5.1-text-variables.md#adow) |
| `$WDAY$` | Value | Day of week number, 0-6 (0=Sunday) | [5.1](5.1-text-variables.md#wday) |
| `$WOY$` | Value | Week of year, 00-53 (Sunday first) | [5.1](5.1-text-variables.md#woy) |
| `$WOYM$` | Value | Week of year, 00-53 (Monday first) | [5.1](5.1-text-variables.md#woym) |

## Screen & state save/restore

| Variable | Type | Returns / Action | Entry |
| --- | --- | --- | --- |
| `$RESET$` | Active | Performs RIP_RESET_WINDOWS (identical to `!\|*`) | [5.1](5.1-text-variables.md#reset) |
| `$EGW$` | Active | Erase Graphics Window | [5.1](5.1-text-variables.md#egw) |
| `$SAVE$` / `$SAVE0-9$` | Active | Save graphics screen (+viewport) to RIPTERM.SAV / RIPTERM_x_.SAV | [5.1](5.1-text-variables.md#save-and-savex) |
| `$RESTORE$` / `$RESTORE0-9$` | Active | Restore saved graphics screen (numbered variants delete the file) | [5.1](5.1-text-variables.md#restore-and-restorex) |
| `$SAVEALL$` | Active | Save all screen attributes (`$STW$ $SCB$ $SMF$ $SAVE$`) | [5.1](5.1-text-variables.md#saveall) |
| `$RESTOREALL$` | Active | Restore all screen attributes (`$RTW$ $RCB$ $RMF$ $RESTORE$`) | [5.1](5.1-text-variables.md#restoreall) |
| `$SMF$` | Active | Save Mouse Fields | [5.1](5.1-text-variables.md#smf) |
| `$RMF$` | Active | Restore Mouse Fields | [5.1](5.1-text-variables.md#rmf) |
| `$MKILL$` | Active | Kill Mouse Fields (like RIP_KILL_MOUSE_FIELDS) | [5.1](5.1-text-variables.md#mkill) |
| `$SCB$` | Active | Save Clipboard to disk | [5.1](5.1-text-variables.md#scb) |
| `$RCB$` | Active | Restore Clipboard from disk (RIPCLIB.BRD) | [5.1](5.1-text-variables.md#rcb) |
| `$PCB$` | Active | Paste Clipboard at last location | [5.1](5.1-text-variables.md#pcb) |

## Special forms

| Form | Where valid | Meaning | Entry |
| --- | --- | --- | --- |
| `$>file$` | Anywhere text variables are allowed | Replay a local file (filename with or without the `.RIP` extension) | [5.3](5.3-local-playback.md) |
| `$?$` | Template definitions only | Insert the fed-in host command text here | [5.2](5.2-host-command-templates.md) |
| `$?x$` | Templates and host commands | Embed the contents of template _x_ | [5.2](5.2-host-command-templates.md#embedded-templates) |
| `$OFF$` | RIP_QUERY `<text>` parameter | Disable a deferred (mode 1/2) query | [5.5](5.5-queries-and-advanced-commands.md#rip_query) |
