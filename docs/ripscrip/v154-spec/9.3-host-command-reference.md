# 9.3 Host Command & Control Character Reference

[◀ Prev: 9.2 Version Identification Reference](9.2-versions.md) · [Contents](README.md)

Everything the terminal sends back to the host - control-character notation, host-bound response sequences, and VT-102 mode keystrokes - plus the four ANSI sequences a host sends to control RIPscrip processing.

## Control-character notation in host commands

Written with a caret (`^`) or backquote (`` ` ``) prefix; translated by the terminal - `^M` sends an actual carriage return (ASCII 13), not two characters. Some systems allow `^^` for a literal caret. (From [5.0 Host Commands & Control Characters](5.0-host-commands.md#control-characters).)

| Notation | Sends                          |
| -------- | ------------------------------ |
| `^@`     | Null (ASCII 0)                 |
| `^C`     | Break (sometimes)              |
| `^G`     | Beep                           |
| `^H`     | Backspace                      |
| `^L`     | Clear Screen (Top of Form)     |
| `^M`     | Carriage Return                |
| `^Q`     | Resume data transmission (XON) |
| `^S`     | Pause data transmission (XOFF) |
| `^[`     | Escape character (ASCII 27)    |

| Notation | Special Keystroke |
| -------- | ----------------- |
| `^[[A`   | Up Arrow          |
| `^[[B`   | Down Arrow        |
| `^[[C`   | Right Arrow       |
| `^[[D`   | Left Arrow        |
| `^[[H`   | Home Key          |
| `^[[K`   | End Key           |
| `^[[L`   | Control Home      |

## Host-bound responses

Sequences the terminal transmits to the host in response to queries and events:

| Trigger | Terminal sends | Reference |
| --- | --- | --- |
| `ESC[!` or `ESC[0!` auto-sense query | `RIPSCRIPxxyyvs` (major `xx`, minor `yy`, vendor `v`, sub-version `s`) - e.g. `RIPSCRIP015410` for RIPterm 1.54 | [1.1](1.1-protocol-and-command-hierarchy.md#ansi-sequences-auto-sensing) |
| `$RIPVER$` text variable | Same `RIPSCRIP…` identification phrase | [5.1](5.1-text-variables.md#ripver) |
| Mouse field click | The field's `<text>` host command, with control characters and text variables expanded | [4.1](4.1-mouse-fields.md#rip_mouse) |
| Mouse button click / hotkey | The button's host-command block, after any template processing (final buffer 0-4095 characters) | [4.2](4.2-buttons.md#rip_button), [5.2](5.2-host-command-templates.md) |
| RIP_QUERY (mode 0, or deferred modes 1/2 on click) | The query's `<text>` with all substitutions expanded | [5.5](5.5-queries-and-advanced-commands.md#rip_query) |
| RIP_FILE_QUERY mode 00 | `1` or `0` (no carriage return) | [5.5](5.5-queries-and-advanced-commands.md#rip_file_query) |
| RIP_FILE_QUERY mode 01 | `1` or `0` + CR | [5.5](5.5-queries-and-advanced-commands.md#rip_file_query) |
| RIP_FILE_QUERY mode 02 | `0` + CR, or `1.size` + CR (e.g. `1.20345`) | [5.5](5.5-queries-and-advanced-commands.md#rip_file_query) |
| RIP_FILE_QUERY mode 03 | `0` + CR, or `1.size.date.time` + CR (e.g. `1.20345.01/02/93.03:04:30`) | [5.5](5.5-queries-and-advanced-commands.md#rip_file_query) |
| RIP_FILE_QUERY mode 04 | `0` + CR, or `1.filename.size.date.time` + CR (e.g. `1.MYFILE.RIP.20345.01/02/93.03:04:30`) | [5.5](5.5-queries-and-advanced-commands.md#rip_file_query) |
| RIP_ENTER_BLOCK_MODE upload refused by user | Ten CAN characters (Ctrl-X, ASCII 24) at one-tenth second intervals | [5.5](5.5-queries-and-advanced-commands.md#rip_enter_block_mode) |

Mouse-coordinate text variables (`$X$`, `$Y$`, `$XY$`, `$XYM$`, `$M$`) substitute position/button data into any of the above host-bound strings - see [9.1 Text Variable Reference](9.1-text-variable-reference.md#mouse). In RIP_QUERY mode 2 (text-window clicks), coordinate variables return two-digit TEXT coordinates instead of four-digit graphics coordinates.

## VT-102 mode keystrokes

With VT-102 keyboard mode enabled (`$VT102ON$`, [5.1](5.1-text-variables.md#vt102on)), these keys send:

| Key          | Sends     |
| ------------ | --------- |
| F1           | `ESC [ M` |
| F2           | `ESC [ N` |
| F3           | `ESC [ O` |
| F4           | `ESC [ P` |
| F5           | `ESC [ Q` |
| F6           | `ESC [ R` |
| F7           | `ESC [ S` |
| F8           | `ESC [ T` |
| F9           | `ESC [ U` |
| F10          | `ESC [ V` |
| PGUP         | `ESC [ I` |
| PGDN         | `ESC [ G` |
| HOME         | `ESC [ H` |
| END          | `ESC [ F` |
| INSERT       | `ESC [ L` |
| CURSOR UP    | `ESC [ A` |
| CURSOR DN    | `ESC [ B` |
| CURSOR LEFT  | `ESC [ C` |
| CURSOR RIGHT | `ESC [ D` |

## Host-to-terminal ANSI control

For completeness, the four ANSI sequences a host may send to control RIPscrip processing ([1.1](1.1-protocol-and-command-hierarchy.md#ansi-sequences-auto-sensing)):

| Sequence | Effect                                           |
| -------- | ------------------------------------------------ |
| `ESC[!`  | Query RIPscrip version (terminal answers, above) |
| `ESC[0!` | Same as `ESC[!`                                  |
| `ESC[1!` | Disable all RIPscrip processing                  |
| `ESC[2!` | Enable RIPscrip processing                       |
