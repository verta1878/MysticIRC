# 9.1 Text Variable Reference

[◀ Prev: 9.0 Command Reference](9.0-command-reference.md) · [Contents](README.md) · [Next: 9.2 Version Identification Reference ▶](9.2-versions.md)

_Reconstructed edition - every claim carries an evidence tag; see [Contents](README.md) for the legend._

Every pre-defined [text variable](../../glossary.md) known for RIPscrip 3.x, with its parameter form, type, effect, and evidence status, linked to its full entry. **Value** variables return text to the host; **Active** variables perform an action on the terminal (some also return data when used to query). Parameters shown in parentheses are optional unless the full entry says otherwise; the 2.0 parameterized forms supersede the 1.54 fixed names (`$SAVE(8)$` vs `$SAVE8$`). The 3.x inventory is triangulated from the RIPtel help files (roughly 60 data-returning and 60 command-performing variables), the demo corpus (269 distinct `$…$` forms in shipping scripts), and SyncTERM's 103-entry built-in table.

_User-defined variables - any `$IDENTIFIER$` with the `*`/`+`/`%`/`#`/`-`/`&` directives, positioning, questions, defaults and format options - are covered in [5.1 Text Variables](5.1-text-variables.md#text-variable-creation-and-query); variables removed or renamed since 1.54 are listed in [5.1's rename note](5.1-text-variables.md)._

The **Evidence** column uses the legend tags in compact form: `2.00a4` (documented in the published ALPHA 4 specification, which 3.x inherits), `WP` (3.0 white paper), `HLP` (RIPtel help / DLL string tables), `corpus` (RIPtel demo scripts), `ST` (SyncTERM implementation), _(hyp)_ (editorial inference). File names, `ripper.c` line numbers and divergence notes live on the full entries. A variable tagged only `2.00a4` is listed as inherited - documented for the engine 3.x inherits, with no independent 3.x-era attestation.
