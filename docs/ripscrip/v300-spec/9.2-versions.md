# 9.2 Version Identification Reference

[◀ Prev: 9.1 Text Variable Reference](9.1-text-variable-reference.md) · [Contents](README.md) · [Next: 9.3 Host Command & Control Character Reference ▶](9.3-host-command-reference.md)

_Reconstructed edition - every claim carries its evidence; see the [Contents](README.md) evidence legend._

Every known RIPscrip version identification string of the 3.x generation, with provenance. The identification phrase replies to the [`ESC[!` auto-sense query](1.1-protocol-and-command-hierarchy.md#ansi-sequences-auto-sensing) and backs [`$RIPVER$`](5.1-text-variables.md#ripver). The phrase format (`RIPSCRIPxxyyvs`) is inherited - see the [v1.54 versions reference](../../1.54/ripscrip/9.2-versions.md) for the field breakdown and the [v2.0 page](../../2.0/ripscrip/9.2-versions.md) for the 2.0 era.

## Known 3.0 identification strings

| String | Reading | Provenance |
| --- | --- | --- |
| `RIPSCRIP03000` | v03.00, revision 0 - 13 characters as printed, without the vendor suffix | RIPTEL.HLP's own FAQ quotes it as the text a user sees on the login line when a MajorBBS/WorldGroup host times out mid-handshake (servers allow only ~1-1.5 s). _Evidence: HLP._ |
| `RIPSCRIP030001` | v03.00, revision 01 - 14 bytes | SyncTERM's RIP 3 reply: `ripver[]` at `sbbs:src/syncterm/ripper.c:7619`, sent without CR/LF via `conn_send(…, 14, 1000)` (ripper.c:18447). _Evidence: SyncTERM._ |

RIPtel 3.1's exact wire reply is **not recoverable** from `strings` over its binaries - only the help-FAQ quote above survives; the full string (any vendor/sub-version digits) remains unverified. Host software probing for "any RIP 3.0" should match on the prefix `RIPSCRIP03` rather than a fixed length. _Evidence: HLP (FAQ quote); binary-strings absence noted in the [research record](../../3.0/research/riptel-help-extraction.md)._

## `$RIPVER$` documentation oddity

RIPTEL.HLP's own example for `$RIPVER$` is `RIPSCRIP015300` - the stale 1.53-era string carried forward from the 1.54 specification's un-updated example, still uncorrected in 1997-era help. It documents nothing about 3.0's own reply; see the [v1.54 versions reference](../../1.54/ripscrip/9.2-versions.md) editor's note on the original contradiction. _Evidence: HLP._
