# 9.3 Host Command & Control Character Reference

[◀ Prev: 9.2 Version Identification Reference](9.2-versions.md) · [Contents](README.md)

_Reconstructed edition - every claim carries its evidence; see the [Contents](README.md) evidence legend._

Everything the terminal sends back to the host in the 3.x generation - control-character notation, host-bound response sequences, and keyboard emulation - plus the four ANSI sequences a host sends to control RIPscrip processing.

## Control-character notation in host commands

Caret (`^`) or backquote (`` ` ``) prefix, translated by the terminal - inherited unchanged; see [5.0 Host Commands](5.0-host-commands.md#control-characters) for the full tables (standard controls `^@`-`^[`, arrow/home/end keystroke sequences). _Evidence: 2.00a4; HLP._

## Host-bound responses

| Trigger | Terminal sends | Reference |
| --- | --- | --- |
| `ESC[!` or `ESC[0!` auto-sense query | `RIPSCRIP03000…` - RIPtel's exact wire reply unrecovered; SyncTERM sends `RIPSCRIP030001`; hosts should prefix-match `RIPSCRIP03` | [9.2](9.2-versions.md), [1.1](1.1-protocol-and-command-hierarchy.md#ansi-sequences-auto-sensing) |
| `$RIPVER$` text variable | The identification phrase | [5.1](5.1-text-variables.md#ripver) |
| Mouse field click | The field's `<text>` host command (with `ID=n:` identity prefix support and inline conditionals), control characters and text variables expanded | [4.2](4.2-mouse-fields-and-pointer.md#rip_mouse), [5.0](5.0-host-commands.md#mouse-field-identities---idn) |
| Button click / hotkey | The button's host-command block, after template/macro processing (incl. `<<NAME>>` macros and `<<IF>>` conditionals) | [4.3](4.3-buttons.md#rip_button), [5.2](5.2-templates-and-conditionals.md) |
| RIP_QUERY (mode 0, deferred modes 1/2, corpus modes 5/6 on hover entry/exit) | The query's `<text>` with all substitutions expanded | [5.5](5.5-file-transfer-and-queries.md#rip_query), [5.0](5.0-host-commands.md#query-deferral-modes) |
| `$TERMINFO()$` / `$IFS()$` capability queries | Capability/feature lists | [5.5](5.5-file-transfer-and-queries.md), [5.1](5.1-text-variables.md) |
| RIP_FILE_QUERY modes 00-04 | `1`/`0`, optionally + CR, `.size`, `.size.date.time`, or `.filename.size.date.time` forms - inherited unchanged | [5.5](5.5-file-transfer-and-queries.md#rip_file_query) |
| RIP_ENTER_BLOCK_MODE upload refused by user | Ten CAN characters (Ctrl-X, ASCII 24) at one-tenth second intervals | [5.5](5.5-file-transfer-and-queries.md#rip_enter_block_mode) |

Mouse-coordinate and state variables substitute into any host-bound string - see [9.1 Text Variable Reference](9.1-text-variable-reference.md). Variables may also be set (`$-=NAME=value$`) and dereferenced (`$&NAME$`) inside host commands before transmission ([5.0](5.0-host-commands.md#setting--reading-user-variables-from-host-commands)).

## Keyboard emulation

RIPtel's terminal-emulation keystrokes (ANSI vs VT-102) are per-Setup/Bookmark client configuration, outside the RIPscrip language - see the [baseline terminal reference](../../baseline/techspecs/ansi-vt-support.md). _Evidence: HLP (Terminal Emulation topics)._

## Host-to-terminal ANSI control

| Sequence | Effect |
| --- | --- |
| `ESC[!` | Query RIPscrip version (terminal answers, above) |
| `ESC[0!` | Same as `ESC[!` |
| `ESC[1!` | Disable all RIPscrip processing |
| `ESC[2!` | Enable RIPscrip processing (see the SyncTERM one-way-door bug note in [1.1](1.1-protocol-and-command-hierarchy.md#ansi-sequences-auto-sensing)) |
