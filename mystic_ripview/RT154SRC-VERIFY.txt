PARSER ANOMALIES
================
1. '$' maps to rcQuery (Level 0 alias for 1Q) — CORRECT per spec.
   Both '1Q' (inside the '1' case) and '$' (standalone) reach rcQuery.

2. 'm' AND 'g' both map to rcGotoXY — CORRECT. RIPscrip spec allows
   both as cursor positioning commands.

3. Level 0 aliases (G,D,M,K,U,u) are parsed OUTSIDE the '1' case block,
   mapping directly to the same rcXxx enum values. This means they
   reach the same executor case arms. CORRECT.

4. rcNoMore is mapped to '#' in the enum but '#' in the parser maps to
   rcResetWindows. rcNoMore is never assigned by the parser — it appears
   as a case in the executor (skips to EOL) but is unreachable.
   ISSUE: rcNoMore exists but is dead code. The spec has no "no more"
   command at '#' — '#' IS ResetWindows. The rcNoMore enum value and
   executor case can be removed. LOW priority, cosmetic.

EXECUTOR DISCREPANCIES
======================
1. rcBeginText (|t) — PARSED but NOT EXECUTED.
   Spec: enters a text region mode where subsequent lines are rendered
   as wrapped text in the text window until EndText is received.
   Impact: RIP scenes using text blocks (!|t...!|E) will silently
   skip the text content. Known limitation for a viewer (not a terminal).

2. rcEndText (|E) — PARSED but NOT EXECUTED.
   Same as above — paired with BeginText.

3. rcRegionText (|1T) — PARSED but NOT EXECUTED.
   Spec: defines a rectangular text region with word wrap.
   Impact: text regions in RIP scenes won't render.

4. rcReadScene (|1R) — PARSED and PARTIALLY EXECUTED.
   Filename is extracted but file loading is a TODO comment.
   Impact: nested .RIP scene includes won't work.

5. rcDefine (|1D) — PARSED, STUB in executor.
   Skips to | delimiter. Header says "wired to riptextvar" but body
   just skips. Low impact — text variables are rare in v1.54 scenes.

6. rcMouse (|1M) — PARSED, STUB (skips to EOL).
   Correct for a viewer — mouse regions are interactive-only.

7. rcFileQuery (|1F) — PARSED, STUB (skips to |).
   Correct for a viewer — file queries are host-client protocol.
