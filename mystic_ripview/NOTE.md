# RIPView — Pascal RIPscrip Viewer

Replaces the JavaScript RIPtermJS viewer. Same 42/42 v1.54 commands,
pixel-perfect rendering, compiled native for all fpc264irc targets.

## Reference Docs (for Kiddo's v2/v3/v4 porting)

Located at `examples/riptermJS/docs/`:
- RIPscrip154.txt — v1.54 spec (implemented, 42/42 commands)
- RIPscrip200a4.txt — v2.0 alpha 4 spec (next target)
- RIPscrip30wp.html — v3.0 working paper (from Wayback Machine, 1998 Telegrafix)

The JS source at `examples/riptermJS/src/` is reference code
for understanding command behavior. Pascal replaces it.
