## Arachne DOS Browser

Reference for v4irc HTML1 rendering engine. GPL v2 licensed.
Supports CGA 640x200 through VESA 1024x768, HTML 4.0 subset, CSS 1.0,
JPEG/PNG/BMP/GIF. Written in C (Borland C++ 3.1).
