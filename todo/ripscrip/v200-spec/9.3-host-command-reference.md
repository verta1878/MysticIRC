# 9.3 Host Command & Control Character Reference

[◀ Prev: 9.2 Version Identification Reference](9.2-versions.md) · [Contents](README.md)

Everything the terminal sends back to the host - control-character notation, host-bound response sequences, and the emulation keystroke sets - plus the four ANSI sequences a host sends to control RIPscrip processing.

## Control-character notation in host commands

Written with a caret (`^`) or backquote (`` ` ``) prefix; translated by the terminal - `^M` sends an actual carriage return, not two characters. (From [5.0 Host Commands](5.0-host-commands.md#control-characters), unchanged from 1.54.)

| Notation | Sends                          |
| -------- | ------------------------------ |
| `^@`     | Null (ASCII 0)                 |
| `^C`     | Break (sometimes)              |
| `^G`     | Beep                           |
| `^H`     | Backspace                      |
| `^L`     | Clear Screen (Top of Form)     |
| `^M`     | Carriage Return                |
| `^Q`     | Resume data transmission (XON) |
| `^S`     | Pause data transmission (XOFF) |
| `^[`     | Escape character (ASCII 27)    |

| Notation | Special Keystroke |
| -------- | ----------------- |
| `^[[A`   | Up Arrow          |
| `^[[B`   | Down Arrow        |
| `^[[C`   | Right Arrow       |
| `^[[D`   | Left Arrow        |
| `^[[H`   | Home Key          |
| `^[[K`   | End Key           |
| `^[[L`   | Control Home      |

## Host-bound responses

Sequences the terminal transmits to the host in response to queries and events:

| Trigger | Terminal sends | Reference |
| --- | --- | --- |
| `ESC[!` or `ESC[0!` auto-sense query | `RIPSCRIP020000` (the literal every shipping 2.x-generation engine carries) | [9.2](9.2-versions.md), [1.1](1.1-protocol-and-command-hierarchy.md#ansi-sequences-auto-sensing) |
| `$RIPVER$` text variable | Same identification phrase | [5.1](5.1-text-variables.md#ripver) |
| Mouse field click | The field's `<text>` host command, with control characters and text variables expanded | [4.2](4.2-mouse-fields-and-pointer.md#rip_mouse) |
| Button click / hotkey | The button's host-command block, after any template processing | [4.3](4.3-buttons.md#rip_button), [5.2](5.2-templates.md) |
| RIP_QUERY (mode 0, or deferred modes on click) | The query's `<text>` with all substitutions expanded | [5.5](5.5-file-transfer-and-queries.md#rip_query) |
| `$TERMINFO()$` / `$IFS()$` / `$LANGUAGE$` queries (via RIP_QUERY) | Capability/feature lists - the 2.x replacement for vendor-code detection | [5.5](5.5-file-transfer-and-queries.md), [5.1](5.1-text-variables.md) |
| RIP_FILE_QUERY mode 00 | `1` or `0` (no carriage return) | [5.5](5.5-file-transfer-and-queries.md#rip_file_query) |
| RIP_FILE_QUERY mode 01 | `1` or `0` + CR | [5.5](5.5-file-transfer-and-queries.md#rip_file_query) |
| RIP_FILE_QUERY mode 02 | `0` + CR, or `1.size` + CR | [5.5](5.5-file-transfer-and-queries.md#rip_file_query) |
| RIP_FILE_QUERY mode 03 | `0` + CR, or `1.size.date.time` + CR | [5.5](5.5-file-transfer-and-queries.md#rip_file_query) |
| RIP_FILE_QUERY mode 04 | `0` + CR, or `1.filename.size.date.time` + CR | [5.5](5.5-file-transfer-and-queries.md#rip_file_query) |
| RIP_ENTER_BLOCK_MODE upload refused by user | Ten CAN characters (Ctrl-X, ASCII 24) at one-tenth second intervals | [5.5](5.5-file-transfer-and-queries.md#rip_enter_block_mode) |

Mouse-coordinate text variables substitute position/button data into any of the above host-bound strings - see [9.1 Text Variable Reference](9.1-text-variable-reference.md).

## Keyboard emulation sets

Unlike 1.54's hardcoded VT-102 keymap, the 2.x client loads its terminal-emulation keystrokes from editable macro files (`ANSI.MAC`, `VT100.MAC`, `TYPE=EMULATION`) selected by the current emulation setting - a client-configuration matter outside the RIPscrip language; see the [baseline terminal reference](../../baseline/techspecs/ansi-vt-support.md) for the documented sets.

## Host-to-terminal ANSI control

The ANSI sequences a host may send to control RIPscrip processing ([1.1](1.1-protocol-and-command-hierarchy.md#ansi-sequences-auto-sensing)):

| Sequence | Effect                                           |
| -------- | ------------------------------------------------ |
| `ESC[!`  | Query RIPscrip version (terminal answers, above) |
| `ESC[0!` | Same as `ESC[!`                                  |
| `ESC[1!` | Disable all RIPscrip processing                  |
| `ESC[2!` | Enable RIPscrip processing                       |
