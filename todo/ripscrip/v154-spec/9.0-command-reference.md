# 9.0 Command Reference

[◀ Prev: 6.2 Asset Delivery & Storage](6.2-asset-delivery-and-storage.md) · [Contents](README.md) · [Next: 9.1 Text Variable Reference ▶](9.1-text-variable-reference.md)

Every RIPscrip 1.54 command with its [command level](../../glossary.md), command type character, argument summary and one-line purpose, each symbol linked to its full entry.

Argument notation follows [1.1 Protocol & Command Hierarchy](1.1-protocol-and-command-hierarchy.md#how-commands-are-documented): `name:width` fields are fixed-width MegaNums, `text` is a trailing text parameter, `...` marks variable-length commands, and `<esc>` denotes the actual Escape character (ASCII 27).
