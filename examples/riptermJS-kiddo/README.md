# riptermIRC — RIP Viewer for Mystic BBS IRC Fork

Based on [RIPtermJS](https://github.com/cgorringe/RIPtermJS) by Carl Gorringe (GPLv3).
Forked and maintained by Kiddo — Mystic BBS IRC Fork.

## What is this?

A browser-based RIPscrip viewer for testing .rip files generated by
chg2rip and the Mystic BBS RIP engines. Works with all CP437 characters
including bytes 128-255 (PabloDraw crashes on these — this viewer doesn't).

## Quick Start

Open `viewer.html` in a browser, drag and drop a .rip file onto it.

Or use with a URL parameter:
```
viewer.html?file=test.rip
```

## Changes from RIPtermJS

- Added standalone viewer.html (no external CSS/JS dependencies)
- Loads local .rip files via drag-and-drop or file picker
- Tested with chg2rip v2.3 output (44KB, 2.8K commands)
- CP437 bytes 128-255 fully supported
- Same BGI engine and RIP parser as Carl's original
