
                                 THDSELCT
                                 --------

    Because the THDPLUS.EXE distributed in this archive is capable of handling 
Renegade 04-05 and Maximus style FILES.BBS updates, this utility is included 
to allow you to select one of those as your BBS type (please note that these 
aspects of THDPLUS.EXE is almost entirely untested).
    Note however that because these BBS types are not recognized by 
THDINSTL.EXE, the output on the first of the final screens of THDINSTL.EXE 
will be somewhat unusual if your BBS type is selected by this utility. This is 
not a cause for concern, it's simply the result of THDINSTL.EXE not being 
prepared for a BBS type which is not defined within its scope of 
configuration.

    THDSELCT.EXE is about as basic a utility as you're going to get. Very 
little planning went into it and it's there just to perform a task in as 
simple a fashion as possible.

DO YOU NEED IT?
---------------
    You ONLY need this utility if you're running Renegade 04-05 (or 
compatible) and want THDPLUS to update your file bases. OR if you run a BBS 
which uses MAXIMUS style FILES.BBS with one line per file and a maximum of 
1024 characters on each line (and you want THDPLUS to update it).

    There is no other use for this utility and it is ONLY of use with the 
THDPLUS distributed with this archive (other versions of THDPLUS will not 
recognize the new BBS types).

WHAT DO I DO WITH IT?
---------------------
    IF you need it, simply put it in the same directory as THDPRO.EXE and run 
it. Answer the questions it asks 'accurately' and your configuration will be 
updated. IF you run THDPRO.EXE in 'secure mode' you will need to run 
THDPRO.EXE /SEC (after updating via this utility) to update your security 
file, otherwise that's all there is to it.
    Do NOT select your BBS type from within THDINSTL.EXE after running this 
utility as that will set your BBS type to one recognized by that version of 
THDINSTL.EXE which will eliminate the changes made by this utility. If however 
you are unhappy with the changes made by this utility, they can be reversed by 
running THDINSTL.EXE and selecting 'none' as your BBS type.


FOR USE WITH
------------
    This utility is designed to work 'specifically' with the THDPRO.EXE 
included in this archive (version 12.5) however it 'should' also work with any 
version 12.x THDPRO.EXE. Although I see no use for it, this utility will also 
work on the OS/2 version of THDPRO.EXE (v 12.5).
    The changes made by this utility will only be recognized by the 
THDPLUS.EXE which is included in this archive. No other version of THDPLUS.EXE 
will recognize the changes made.
