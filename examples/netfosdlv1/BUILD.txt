netfosdl — DOS FOSSIL driver — BUILD INSTRUCTIONS
==================================================

REQUIRES a REAL-MODE 16-bit Pascal compiler:
  * FPC 3.0+ with the i8086-msdos target  (the fpc264irc ppcross8086), OR
  * Turbo Pascal 7 / Borland Pascal 7

It will NOT build with FPC 2.6.4's stock DOS target (go32v2) — that is a
32-bit protected-mode target, and this is a 16-bit real-mode TSR. Real-mode
i8086 support was added to FPC in 3.0.0. The fpc264irc cross-compiler
(ppcross8086) is FPC 3.2.2 targeting i8086/msdos — use that.

BUILD (fpc264irc ppcross8086):
  ppcross8086 -Tmsdos -Wmhuge -Mobjfpc -CX -XX -Ch4096 \
    -Fu<fpc264irc>/bin/units/i8086-msdos -Fu. \
    -oNETFOSDL.EXE netfosdl.pas

  Flags that matter:
    -Tmsdos    real-mode DOS target
    -Wmhuge    huge memory model (the i8086 RTL is huge-model only)
    -CX -XX    smart-linking (required with that RTL)
    -Ch4096    4 KB local heap

TEST PROGRAMS (same flags):
  FOSTEST.EXE  FOSFULL.EXE  FOSTEST2.EXE

VERIFIED: builds 0 errors; DOSBox-X (cputype=386, fpu=true, serial1=dummy):
  Init AX=1954 BL=33 BH=5, Status AH=60, SetBaud AX=6000, Deinit clean.

UNITS: netfosdl.pas uses fossil.pas, serial.pas, serial_irq.pas — keep all
four together in the build directory.
