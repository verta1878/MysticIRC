# THD ProScan / TD ProScan

Archive file scanner for BBS systems.

## Files

- `thdpro12.zip` — Original THD ProScan v12 by Pain Software
- `tdpro12.zip` — Clean room remake

## Notes

THD ProScan scans uploaded archive files for integrity,
embedded ANSI art (FILE_ID.DIZ), viruses, and validates
file descriptions. Used by PCBoard, Mystic, and other BBS systems.
